Contributing
Want to help improve the booth request process? Bug reports, fixes and suggestions are welcome as issues or pull requests on the opensuse/request repository.

Get notified of booth requests
Want to be notified of the forms being submitted for booth requests so you can help staff an event? Open a pull request against the opensuse/request repository adding your email address to the notification list, or open an issue asking to be added and providing your email address. You can remove yourself the same way at any time.

Please note that anything committed to the repository is public, so only add an address you're comfortable having visible on GitHub.

Something not working?
If you're not receiving notifications or aren't sure how to sign up, open an issue and tag @ddemaio so it can be looked into.
